# Starting with 0.7.1000

Version **0.7.1000** is the first supported conUI profile and preset baseline. It starts with a fresh conUI profile; profiles and presets from earlier patches are not migrated.

Use [Getting started](getting-started.md) to choose one of the eleven built-in presets, your role and the parts of the interface you want conUI to handle. conUI Center is the default.

From this baseline onward, updates preserve supported profile settings and personal frame positions. Use [Updating](updating.md) for installation instructions and [Saved data](saved-data.md) for the supported backup and restore controls.
